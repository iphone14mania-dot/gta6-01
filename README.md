SOLMAR BAY: sun-soaked open-world crime — 8 story jobs, 5-star SBPD with roadblocks and Air One, weapon slots, garage upgrades, crew, respect ranks, saves, radio.

A 2D top-down open-world crime game built from scratch in plain JavaScript — zero libraries, zero network requests, all art drawn in code, all sound synthesized with WebAudio. Drive the seeded 3600×2700 city of Solmar Bay, work eight story jobs for fixer Rosa, dodge a 5-star wanted system with patrol cars, foot cops, roadblocks and the Air One helicopter, and build Leo Marlow from nobody to Bay Legend.

## Run it

```sh
node serve.ts
```

Then open http://localhost:4173/ — WASD to drive or walk, mouse to aim, click to shoot, F to enter or exit a car, Q to switch weapons, E to interact, R for radio, P to pause. Your progress saves automatically in localStorage.
